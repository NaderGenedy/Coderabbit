Full matrix, not fixed seats

Mission: govern the CALON panel so a claim cannot pass merely because the model assigned to “audit” failed to notice it.

One idea

An agent is Claude, Codex, Kimi, or Grok. A lens is Methodology, Implementation, Adversarial audit, or Clinical/publication reality. They are different dimensions.

Fixed seats — rejectFull matrix — use
Claude only does methodClaude answers all four lenses
Codex only does implementationCodex answers all four lenses
Kimi/Grok only auditKimi/Grok also answer method, implementation, and clinical reality
Four partial opinionsSixteen positions: 4 agents × 4 lenses
Why this matters: if the “auditor” disputes the “methodologist,” a fixed-seat design cannot distinguish a real scientific disagreement from two jobs emphasizing different things. In a full matrix, all four agents address the same lens, making disagreement interpretable.

The live loop

  1. Gate 0: prove all four CLIs use their subscriptions.
  2. Resource audit: each agent reads the permitted evidence independently; no raw participant data.
  3. Round 1: blind, four agents × four lenses.
  4. Round 2+: each attacks named claims from another agent, under a named lens.
  5. Close: consensus.mjs, not a model, decides. Open objections mean another round; DEADLOCK is an honest outcome.

Retrieval check

Which instruction preserves the design?

Practical rule

When you read a panel output, ask: “Which agent made this claim, under which lens, and what artefact would settle it?” If one of those is absent, the claim is not ready for consensus.
